Open an issue on GitHub. Say which device and version, and what you expected.

Before you report

  • Never share a recovery phrase or signing key, in an issue or anywhere else. We will never ask for one.
  • A transaction's hex, or its id on a public network, is safe to share and usually the quickest way to show a problem.
  • Say which version you have: it's in About Cardano TxWorkshop on the Mac, and on the app's App Store page elsewhere.

Common questions

"cardano-node is not answering"

The node isn't running, or the socket path in the provider's settings points somewhere else. Start the node, and check the path matches its --socket-path.

Why can't I pick a local node on the App Store version?

The App Store keeps apps in a sandbox that can't reach a node's socket or run cardano-cli. The Mac download can.

An input shows "Not found, or already spent"

The chain no longer has that output: it was spent, or never existed on this network. Check the document's network in the toolbar.
